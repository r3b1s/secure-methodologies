# OSPS-QA-06.03

- **Control:** OSPS-QA-06, Use Automated Testing in CI/CD Pipelines (Quality)
- **Level:** 3+
- **Exact text:** [OSPS Baseline v2026.08.28](https://baseline.openssf.org/versions/2026-08-28#osps-qa-0603), the authority

> Summarised in this skill's own words.

- **Requires:** a policy that major changes add or update automated tests.
- **Meet it:** state the policy in contributor documentation, including what counts as a
  major change.
- **Verify:** read it and compare with recent significant changes.
