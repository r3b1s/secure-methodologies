# OSPS-DO-04.01

- **Control:** OSPS-DO-04, Publish Support Scope and Duration (Documentation)
- **Level:** 3+, after a release
- **Exact text:** [OSPS Baseline v2026.08.28](https://baseline.openssf.org/versions/2026-08-28#osps-do-0401), the authority

> Summarised in this skill's own words.

- **Requires:** a statement of the scope and duration of support for each release.
- **Meet it:** a support policy (for example `SUPPORT.md`, or a section of the security
  policy) covering which releases are supported, for how long, and with what kind of
  fixes.
- **Verify:** read it and check it matches recent practice.
