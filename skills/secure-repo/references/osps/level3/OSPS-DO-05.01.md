# OSPS-DO-05.01

- **Control:** OSPS-DO-05, Document Security Update Scope and Duration (Documentation)
- **Level:** 3+, after a release
- **Exact text:** [OSPS Baseline v2026.08.28](https://baseline.openssf.org/versions/2026-08-28#osps-do-0501), the authority

> Summarised in this skill's own words.

- **Requires:** a statement of when releases or versions stop receiving security updates.
- **Meet it:** state the security-update policy, for example "only the latest release".
- **Verify:** read it.
