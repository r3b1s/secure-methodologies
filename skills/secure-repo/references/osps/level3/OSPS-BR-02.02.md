# OSPS-BR-02.02

- **Control:** OSPS-BR-02, Assign Unique Version Identifiers (Build and Release)
- **Level:** 3+
- **Exact text:** [OSPS Baseline v2026.08.28](https://baseline.openssf.org/versions/2026-08-28#osps-br-0202), the authority

> Summarised in this skill's own words.

- **Requires:** every asset in a release is clearly tied to the release identifier or its
  own unique identifier.
- **Meet it:** name or tag each asset with the release version.
- **Verify:** inspect the assets of recent releases.
