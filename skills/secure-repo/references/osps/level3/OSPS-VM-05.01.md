# OSPS-VM-05.01

- **Control:** OSPS-VM-05, Publish and Enforce a Dependency Remediation Policy (Vulnerability Management)
- **Level:** 3+
- **Exact text:** [OSPS Baseline v2026.08.28](https://baseline.openssf.org/versions/2026-08-28#osps-vm-0501), the authority

> Summarised in this skill's own words.

- **Requires:** a policy setting a threshold for remediating software composition
  analysis (SCA) findings about vulnerabilities and licences.
- **Meet it:** document which findings must be fixed and how fast, and how they are found
  and prioritised. The threshold is the human's decision.
- **Verify:** read the policy and compare with open findings.
