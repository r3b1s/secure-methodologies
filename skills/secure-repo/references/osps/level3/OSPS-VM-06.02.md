# OSPS-VM-06.02

- **Control:** OSPS-VM-06, Publish and Enforce an Application Security Testing Policy (Vulnerability Management)
- **Level:** 3+
- **Exact text:** [OSPS Baseline v2026.08.28](https://baseline.openssf.org/versions/2026-08-28#osps-vm-0602), the authority

> Summarised in this skill's own words.

- **Requires:** every change is checked automatically against a documented policy for
  security weaknesses, and blocked on violation unless declared non-exploitable.
- **Meet it:** a required SAST status check on change requests. The tool is the human's
  choice.
- **Verify:** inspect the check and that it is required.
