# OSPS-DO-03.02

- **Control:** OSPS-DO-03, Publish Provenance Verification Instructions (Documentation)
- **Level:** 3+, after a release
- **Exact text:** [OSPS Baseline v2026.08.28](https://baseline.openssf.org/versions/2026-08-28#osps-do-0302), the authority

> Summarised in this skill's own words.

- **Requires:** instructions for verifying the expected identity of the person or process
  that authored a release.
- **Meet it:** publish the signing key IDs, or the expected signing identity and issuer.
- **Verify:** check that a recent release's signature matches the documented identity.
