# OSPS-SA-03.02

- **Control:** OSPS-SA-03, Maintain a Project Security Assessment (Security Assessment)
- **Level:** 3+, after a release
- **Exact text:** [OSPS Baseline v2026.08.28](https://baseline.openssf.org/versions/2026-08-28#osps-sa-0302), the authority

> Summarised in this skill's own words.
>
> The Baseline applies this only after a release. This skill recommends doing the
> assessment before a repository is first published as well; see
> [threat-modeling.md](../../threat-modeling.md).

- **Requires:** threat modelling and attack-surface analysis of critical code paths,
  functions and interactions.
- **Meet it:** follow [threat-modeling.md](../../threat-modeling.md), listing each threat
  and the response to it.
- **Verify:** check every threat has an agreed response and the model matches the code.
