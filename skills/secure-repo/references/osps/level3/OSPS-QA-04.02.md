# OSPS-QA-04.02

- **Control:** OSPS-QA-04, Enforce Security Requirements on All Codebases (Quality)
- **Level:** 3+, after a release
- **Exact text:** [OSPS Baseline v2026.08.28](https://baseline.openssf.org/versions/2026-08-28#osps-qa-0402), the authority

> Summarised in this skill's own words.

- **Requires:** in a release built from several repositories, every subproject enforces
  security requirements at least as strict as the primary one.
- **Meet it:** apply the same Baseline requirements, and any extra checks, to each
  subproject.
- **Verify:** assess each subproject as you would the primary.
