# OSPS-SA-03.01

- **Control:** OSPS-SA-03, Maintain a Project Security Assessment (Security Assessment)
- **Level:** 2+, after a release
- **Exact text:** [OSPS Baseline v2026.08.28](https://baseline.openssf.org/versions/2026-08-28#osps-sa-0301), the authority

> Summarised in this skill's own words.
>
> The Baseline applies this only after a release. This skill recommends doing the
> assessment before a repository is first published as well; see
> [threat-modeling.md](../../threat-modeling.md).

- **Requires:** a security assessment of the most likely and most damaging security
  problems the software could have.
- **Meet it:** follow [threat-modeling.md](../../threat-modeling.md); keep the result
  current with new features and breaking changes.
- **Verify:** read the assessment and check it covers the system as the code shows it.
