# OSPS-VM-04.01

- **Control:** OSPS-VM-04, Publish Discovered Vulnerabilities (Vulnerability Management)
- **Level:** 2+
- **Exact text:** [OSPS Baseline v2026.08.28](https://baseline.openssf.org/versions/2026-08-28#osps-vm-0401), the authority

> Summarised in this skill's own words.

- **Requires:** public data about discovered vulnerabilities.
- **Meet it:** publish advisories in a predictable public place (for example CVE entries
  or the platform's advisories), with affected versions, how to tell if you are affected,
  and how to fix or mitigate.
- **Verify:** check where past vulnerabilities were published, and that the documentation
  says where to look.
