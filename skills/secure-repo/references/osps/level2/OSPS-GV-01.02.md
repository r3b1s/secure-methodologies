# OSPS-GV-01.02

- **Control:** OSPS-GV-01, Publish Project Roles and Responsibilities (Governance)
- **Level:** 2+
- **Exact text:** [OSPS Baseline v2026.08.28](https://baseline.openssf.org/versions/2026-08-28#osps-gv-0102), the authority

> Summarised in this skill's own words.

- **Requires:** descriptions of the roles and responsibilities of project members.
- **Meet it:** describe each role (for example maintainer, reviewer, release manager) and
  what it may do.
- **Verify:** read it and check it matches the platform's permissions.
