# OSPS-BR-02.01

- **Control:** OSPS-BR-02, Assign Unique Version Identifiers (Build and Release)
- **Level:** 2+
- **Exact text:** [OSPS Baseline v2026.08.28](https://baseline.openssf.org/versions/2026-08-28#osps-br-0201), the authority

> Summarised in this skill's own words.

- **Requires:** each official release has a unique version identifier.
- **Meet it:** follow one scheme consistently (for example SemVer, CalVer or a commit ID)
  and record it in the release process.
- **Verify:** list past releases and check that identifiers are unique and follow the
  scheme.
