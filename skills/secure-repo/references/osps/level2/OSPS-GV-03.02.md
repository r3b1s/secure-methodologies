# OSPS-GV-03.02

- **Control:** OSPS-GV-03, Publish Contribution Guide (Governance)
- **Level:** 2+
- **Exact text:** [OSPS Baseline v2026.08.28](https://baseline.openssf.org/versions/2026-08-28#osps-gv-0302), the authority

> Summarised in this skill's own words.

- **Requires:** a guide for code contributors setting out what an acceptable contribution
  must meet.
- **Meet it:** extend the contribution guide with coding standards, testing requirements
  and submission rules, so it serves contributors and approvers alike.
- **Verify:** read it and compare it with what reviews actually ask for.
