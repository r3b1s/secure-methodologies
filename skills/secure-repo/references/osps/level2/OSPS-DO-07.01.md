# OSPS-DO-07.01

- **Control:** OSPS-DO-07, Provide Instructions on How to Build From Source (Documentation)
- **Level:** 2+
- **Exact text:** [OSPS Baseline v2026.08.28](https://baseline.openssf.org/versions/2026-08-28#osps-do-0701), the authority

> Summarised in this skill's own words.

- **Requires:** instructions for building the software, including the libraries,
  frameworks, SDKs and dependencies it needs.
- **Meet it:** document the prerequisites and build commands, in contributor
  documentation or as build automation targets.
- **Verify:** follow the instructions in a clean environment, if the project's
  constraints allow it.
