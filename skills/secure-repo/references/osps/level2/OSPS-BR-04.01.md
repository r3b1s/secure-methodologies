# OSPS-BR-04.01

- **Control:** OSPS-BR-04, Publish Change Log With Release (Build and Release)
- **Level:** 2+
- **Exact text:** [OSPS Baseline v2026.08.28](https://baseline.openssf.org/versions/2026-08-28#osps-br-0401), the authority

> Summarised in this skill's own words.

- **Requires:** each official release includes a descriptive log of functional and
  security changes.
- **Meet it:** write human-readable release notes that go beyond commit messages and call
  out security impact. The Baseline suggests a `## Changelog` heading for machine
  readability.
- **Verify:** read the notes of recent releases.
