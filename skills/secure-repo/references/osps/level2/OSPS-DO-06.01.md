# OSPS-DO-06.01

- **Control:** OSPS-DO-06, Publish Dependency Management Policy (Documentation)
- **Level:** 2+, after a release
- **Exact text:** [OSPS Baseline v2026.08.28](https://baseline.openssf.org/versions/2026-08-28#osps-do-0601), the authority

> Summarised in this skill's own words.

- **Requires:** a description of how the project selects, obtains and tracks its
  dependencies.
- **Meet it:** document the criteria for adding a dependency, where dependencies come from
  and how versions are pinned and updated. The choices themselves are the human's.
- **Verify:** compare the description with the manifests, lock files and update tooling.
