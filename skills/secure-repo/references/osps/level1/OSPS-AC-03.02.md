# OSPS-AC-03.02

- **Control:** OSPS-AC-03, Protect the Primary Branch from Accidental Modification (Access Control)
- **Level:** 1+
- **Exact text:** [OSPS Baseline v2026.08.28](https://baseline.openssf.org/versions/2026-08-28#osps-ac-0302), the authority

> Summarised in this skill's own words.

- **Requires:** deleting the primary branch is treated as sensitive and needs explicit
  confirmation.
- **Meet it:** a branch protection rule or ruleset that restricts deletion of the primary
  branch.
- **Verify:** inspect the rule's configuration.
