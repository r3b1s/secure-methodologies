# OSPS-QA-01.02

- **Control:** OSPS-QA-01, Publish Source Code and Change History (Quality)
- **Level:** 1+
- **Exact text:** [OSPS Baseline v2026.08.28](https://baseline.openssf.org/versions/2026-08-28#osps-qa-0102), the authority

> Summarised in this skill's own words.

- **Requires:** a public record of every change, who made it and when.
- **Meet it:** keep the commit history public, and avoid squashing or rewriting it in ways
  that hide authorship.
- **Verify:** check the history is public. Before publishing an existing repository, the
  history also has to be checked for secrets and personal information; see
  [stages/pre-publication-audit.md](../../stages/pre-publication-audit.md). Rewriting
  history is the human's decision.
