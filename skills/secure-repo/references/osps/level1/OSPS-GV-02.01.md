# OSPS-GV-02.01

- **Control:** OSPS-GV-02, Provide Public Discussion Mechanisms (Governance)
- **Level:** 1+
- **Exact text:** [OSPS Baseline v2026.08.28](https://baseline.openssf.org/versions/2026-08-28#osps-gv-0201), the authority

> Summarised in this skill's own words.

- **Requires:** at least one public place to discuss proposed changes and usage problems.
- **Meet it:** an issue tracker, discussion forum, mailing list or chat, linked from the
  README.
- **Verify:** check it exists, is public and is linked.
