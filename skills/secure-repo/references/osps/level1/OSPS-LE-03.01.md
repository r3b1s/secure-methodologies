# OSPS-LE-03.01

- **Control:** OSPS-LE-03, Maintain and Release Licenses in a Well Known Location (Legal)
- **Level:** 1+
- **Exact text:** [OSPS Baseline v2026.08.28](https://baseline.openssf.org/versions/2026-08-28#osps-le-0301), the authority

> Summarised in this skill's own words.
>
> This guidance says what the controls require. It is not legal advice; choosing a licence
> or a contributor agreement is the human's decision.

- **Requires:** the source licence is kept in the repository's `LICENSE` file, `COPYING`
  file, `LICENSES/` directory or `LICENSE/` directory (an extension is allowed).
- **Meet it:** add the licence in one of those places, in every repository of the project.
- **Verify:** check the file exists and matches the licence declared elsewhere (package
  metadata, README).
