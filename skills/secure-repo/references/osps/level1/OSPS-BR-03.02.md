# OSPS-BR-03.02

- **Control:** OSPS-BR-03, Use Encrypted Channels for Development & Release Activity (Build and Release)
- **Level:** 1+
- **Exact text:** [OSPS Baseline v2026.08.28](https://baseline.openssf.org/versions/2026-08-28#osps-br-0302), the authority

> Summarised in this skill's own words.

- **Requires:** official distribution channels are protected against
  adversary-in-the-middle attacks with cryptographically authenticated channels.
- **Meet it:** distribute over HTTPS, through a trusted package registry, or with signed
  releases.
- **Verify:** check every documented download or install method, including install
  scripts and the URLs they fetch.
