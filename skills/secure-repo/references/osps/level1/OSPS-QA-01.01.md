# OSPS-QA-01.01

- **Control:** OSPS-QA-01, Publish Source Code and Change History (Quality)
- **Level:** 1+
- **Exact text:** [OSPS Baseline v2026.08.28](https://baseline.openssf.org/versions/2026-08-28#osps-qa-0101), the authority

> Summarised in this skill's own words.

- **Requires:** the source repository is publicly readable at a stable URL.
- **Meet it:** host it publicly and avoid moving it. If it is mirrored, say clearly which
  copy is primary.
- **Verify:** open the URL without signing in. Before publication, this is the step the
  human approves last.
