# OSPS-AC-02.01

- **Control:** OSPS-AC-02, Restrict Collaborator Permissions (Access Control)
- **Level:** 1+
- **Exact text:** [OSPS Baseline v2026.08.28](https://baseline.openssf.org/versions/2026-08-28#osps-ac-0201), the authority

> Summarised in this skill's own words.

- **Requires:** new collaborators get permissions only by explicit assignment, or start
  with the lowest permissions available.
- **Meet it:** use the platform's default lowest role for new members and grant more only
  when needed.
- **Verify:** check the default role for new members and how invitations assign roles.
  Some platforms give every collaborator on a personal repository the same access; note
  that in the result.
