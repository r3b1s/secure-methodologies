# OSPS-QA-04.01

- **Control:** OSPS-QA-04, Enforce Security Requirements on All Codebases (Quality)
- **Level:** 1+
- **Exact text:** [OSPS Baseline v2026.08.28](https://baseline.openssf.org/versions/2026-08-28#osps-qa-0401), the authority

> Summarised in this skill's own words.

- **Requires:** a project with several repositories documents which codebases belong to
  it.
- **Meet it:** list each repository compiled into a release, with its status and purpose.
- **Verify:** compare the list with the build's actual sources. Not applicable to a
  single-repository project.
