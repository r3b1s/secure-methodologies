# OSPS-DO-02.01

- **Control:** OSPS-DO-02, Provide Mechanisms for Reporting Defects (Documentation)
- **Level:** 1+, after a release
- **Exact text:** [OSPS Baseline v2026.08.28](https://baseline.openssf.org/versions/2026-08-28#osps-do-0201), the authority

> Summarised in this skill's own words.

- **Requires:** a guide for reporting defects.
- **Meet it:** point to the issue tracker (the platform's default is recommended) and say
  what a good report contains and how reports are handled.
- **Verify:** follow the documented route and check it works.
