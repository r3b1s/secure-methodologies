# OSPS-LE-02.02

- **Control:** OSPS-LE-02, Ensure Project Licenses are Fully Open Source (Legal)
- **Level:** 1+
- **Exact text:** [OSPS Baseline v2026.08.28](https://baseline.openssf.org/versions/2026-08-28#osps-le-0202), the authority

> Summarised in this skill's own words.
>
> This guidance says what the controls require. It is not legal advice; choosing a licence
> or a contributor agreement is the human's decision.

- **Requires:** the licence of released assets meets the same definitions. It may differ
  from the source licence.
- **Meet it:** as for LE-02.01, for any licence shipped with release assets.
- **Verify:** inspect the licence included with recent release assets. Not applicable
  until the project releases assets.
