# OSPS-DO-01.01

- **Control:** OSPS-DO-01, Publish User Guides for Basic Functionality (Documentation)
- **Level:** 1+, after a release
- **Exact text:** [OSPS Baseline v2026.08.28](https://baseline.openssf.org/versions/2026-08-28#osps-do-0101), the authority

> Summarised in this skill's own words.

- **Requires:** user guides for all basic functionality.
- **Meet it:** document how to install, configure and use each basic feature. Put highly
  visible warnings on dangerous or destructive actions.
- **Verify:** compare the documented features with what the code actually offers
  (ground rule 3), and look for undocumented destructive actions.
